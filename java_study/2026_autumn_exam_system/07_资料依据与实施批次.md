## 学习资源怎么用

| 知识缺口 | 读到什么程度 | 在本项目中验证 |
|---|---|---|
| HTTP / Servlet / Tomcat | 请求响应、JSON、状态码、容器和 Servlet 作用 | Apifox 发请求，解释进入 Controller 前经过什么 |
| Spring IoC/DI | Bean、组件扫描、构造器注入 | 解释 Controller 为什么能拿到 Service |
| Spring MVC | 路由、请求参数、响应转换、校验、异常处理 | 完成一条正确请求和一条错误请求 |
| Spring Boot | starter、自动配置、application.yml、启动入口 | 能解释 pom 中每个新增依赖和配置项 |
| MyBatis | Mapper/XML、绑定参数、结果映射、动态条件 | 从 SQL 到 Java 对象追踪一次查询 |
| 事务与锁 | 多写入一致性、回滚、同一行并发处理 | 交卷保存中断和重复请求测试 |
| Git 与接口协作 | 功能分支、明确提交、先对齐接口 | 修改功能时同步代码、文档和案例 |

原有基础课和 Demo 可作为补课材料，本次仓库不包含这些个人文件。正式项目使用 MySQL，不以旧 Demo 的 H2 默认数据库作为正式项目完成证据。
