# 在线考试系统后端（分批交付中）

本仓库正在以真实提交时间分批整理现有后端，当前不是最终交付版本。使用 JDK 8、Spring Boot 2.7.18、MyBatis 和 MySQL；不包含前端或个人学习资料。

交付顺序：项目基础与登录 → 资料/课程权限 → 教师题库/成绩查询 → 考试快照与事务判分 → 自动化测试 → 接口与最终运行说明。请以当前目录实际源码为准，尚未交付的接口不能视为已提供。

在 backend 目录执行 `mvn package` 构建当前阶段。测试文件将在测试批次加入，在此之前编译成功不表示完整测试通过。最终阶段提供隔离的 H2 测试与完整 API 使用说明。

应用数据库配置在 backend/src/main/resources/application.yml，密码必须通过本机环境变量 DB_PASSWORD 设置，不提交仓库。启动不自动建表或导入数据；不要对已有库执行初始化 SQL。当前默认库名 exam_system_fullstack，可通过 DB_URL 覆盖。

说明：采用 Boot 2.7 以兼容 Java 8，本地教学考核用途，不应未经升级和安全评估直接部署公网。当前提交只是阶段交付记录，不是独立开发时长的证明。
