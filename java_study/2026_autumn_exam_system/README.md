# 在线考试系统

前后端分离的在线考试项目，面向教师和学生，提供题库管理、在线答题、自动判分、重考及历史成绩查询。

## 核心流程

教师维护课程题目 → 学生登录并查看已选课程 → 开始考试并保存题目快照 → 提交答案 → 后端判分并保存 → 页面展示成绩 → 明确点击重考 → 产生新答卷 → 教师查看所有历史成绩。

## 关键设计

- 权限校验：教师只能管理自己的课程，学生只能访问自己的答卷与成绩。
- 服务端判分：只接收学生选项，不接受客户端指定分数或标准答案。
- 事务与幂等：交卷原子保存，重复交卷返回已保存结果。
- 题目快照：题库修改不影响已经开始的考试；重考创建新答卷并保留历史。

以上均为待实现的设计目标，不代表已经通过测试。
