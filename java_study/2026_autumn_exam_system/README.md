## 技术方案

| 项目 | 计划选择 | 在项目中的作用 |
|---|---|---|
| JDK | 8 | 编译和运行 Java 程序 |
| Spring Boot | 2.7.18 | 启动应用、组织配置和依赖，内置 Tomcat |
| Spring / Spring MVC | Boot 配套的 Spring 5.3 系列 | 管理对象、接收 HTTP 请求、返回 JSON |
| MyBatis Starter | 2.3.2 | 将 Java 方法与明确写出的 SQL 对应 |
| MySQL | 8.x，InnoDB，utf8mb4 | 保存用户、题目、答卷和历史成绩 |
| 登录 | HttpSession + Cookie | 从服务端判断当前用户与角色 |
| 接口协作 | Apifox | 保存接口说明以及成功、失败、异常案例 |
| 前端 | 由前端队友按其已掌握的技术实现 | 页面、表单、答题交互和成绩展示 |

Spring Boot 2.7.18 支持 Java 8，MyBatis Starter 2.3 系列对应 Boot 2.7 / Java 8；依据见[官方兼容说明](07_资料依据与实施批次.md)。这些是本次 JDK 8 学习项目的兼容选择。

本次实际检查：Java 为 Temurin 1.8.0_492；Maven 为 3.9.16，使用的也是 Java 8；名为 MySQL80 的服务正在运行。尚未连接数据库核对服务端版本、账号权限或执行 SQL。

## 最重要的一条业务链

教师维护课程题目 → 学生登录并查看已选课程 → 开始考试并保存题目快照 → 提交答案 → 后端判分并保存 → 页面展示成绩 → 明确点击重考 → 产生新答卷 → 教师查看所有历史成绩。

优先做出的技术特点是：交卷事务与防重复交卷、题目快照保留历史。它们直接解决考试系统的问题，答辩时有代码、有异常场景、有结果可以展示。
