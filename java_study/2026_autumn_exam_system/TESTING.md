## 重复运行

普通测试在 backend 目录执行：

```powershell
mvn test
```

默认只使用内存库，不访问真实 MySQL。若要在真实 MySQL 上测试，必须先准备一个可清空的本机专用库，库名必须为 `exam_system_test`，再配置：

```powershell
$env:TEST_DB_URL = 'jdbc:mysql://127.0.0.1:13306/exam_system_test?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true'
$env:TEST_DB_USERNAME = '你的专用测试账号'
# TEST_DB_PASSWORD 通过当前进程安全配置，不要提交到仓库。
$env:ALLOW_TEST_DB_RESET = 'true'
mvn test
```

该模式会删除六张测试表里的数据并重新插入虚构演示数据，只能用于可清空的测试库。代码检查库名、主机和明确允许标志，但仍需操作者确认连接地址。运行完成后清除这些测试环境变量，避免误用。

真实 HTTP 验证：先在未修改演示题库的独立库启动应用，再运行 `scripts/smoke.ps1`。脚本会新增考试记录，不会删除历史数据。
